# Changelog

## 0.1.0 (experimental source prototype)
- Replace the previous custom-message architecture with the game's own Mirror `RpcChangeTimeScale` RPC.
- Host-only installation; no guest-side mod required.
- Host F9 pause/resume, simple host overlay and key configuration.
- State cleanup during phase transitions, run end and plugin unload.
- Native RPC refresh for late joiners.
